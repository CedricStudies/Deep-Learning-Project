# Machine Learning Project

This project explores the development of two Deep Learning models: a custom Convolutional Neural Network (CNN) and a InceptionV3 Transfer Learning Model to classify a given image into 3 classes: `airplane`, `automobile`, and `truck`. The workflow included data preparation, model development, performance evaluation, model optimization, and model comparison.

## Project files

- `231867A_project.ipynb` - Jupyter notebook housing main code
- `dataset_transport` - dataset
- `EGT214_Project.pdf` - project brief
- `README.md` - this file

## Models and evaluation

The Jupyter notebook explores and evaluates 2 models:

1. Custom CNN Model
2. InceptionV3

Performance is assessed using training and validation accuracy and loss, along with classification metrics, confusion matrices, and model comparison plots. The notebook also explores regularization, data augmentation, fine-tuning, and other optimization techniques.

## Getting started

1. Clone or download this repository:

```
git clone https://github.com/CedricStudies/Deep-Learning-Project.git
```

2. Navigate to the project folder:

```
cd Deep-Learning-Project
```

3. Install the required Python packages:

   ```bash
   pip install tensorflow numpy pandas matplotlib seaborn scikit-learn jupyter
   ```

4. This project was completed on Google Colab where the dataset was mounted there. If using a local IDE, update the dataset path. Open `231867A_project.ipynb` and run all cells.
